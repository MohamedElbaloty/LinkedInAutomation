# LinkedIn AI Organic Growth Publisher & Web Dashboard 🤖🚀

نظام آلي متكامل مدعوم بالذكاء الاصطناعي لاكتشاف أحدث ابتكارات وأخبار الذكاء الاصطناعي العالمية وصياغة منشورات احترافية باللغة العربية للينكد إن وتوليد إنفوجرافيك 16:9 بنمط **Nano Banana Pro**، ونشرها آلياً على لينكد إن وتلجرام وفق جدول استراتيجي للنمو الأورجانيك، مع لوحة تحكم ويب عصرية ودعم كامل للنشر السحابي على **Railway** بحماية 100% من الحظر.

---

## 🌟 أبرز المميزات

1. **لوحة تحكم تفاعلية (Web Dashboard):**
   - مبنية بـ **FastAPI** وتصميم Dark Glassmorphism فخم ومتجاوب.
   - زر **"نشر الآن (Publish Now)"** لاختبار عملية النشر ومشاهدة النتيجة في الحال مع شريط تقدم مباشر.
   - محرر مواعيد مرن لإضافة أو تعديل أوقات النشر اليومية بنقرة واحدة.
   - استعراض قائمة الانتظار (Live Queue) وسجل المنشورات السابقة.

2. **حماية 100% لحساب لينكد إن (Anti-Ban Architecture):**
   - يعتمد على **LinkedIn Official REST API** (إصدار `202401`) ونظام OAuth 2.0 المعتمد.
   - تشغيل آمن تماماً على خوادم السحاب (Railway / Cloud) دون التعرض لحظر مراكز البيانات أو حظر المتصفحات الخفية.

3. **استراتيجية النمو الأورجانيك على LinkedIn:**
   - استهداف الساعات الذهبية للتفاعل: **08:45 صباحاً**، **13:15 ظهراً**، و **18:45 مساءً**.
   - هيكل محتوى هندسي يجمع بين العنوان الجذاب (Hook)، والتحليل العميق، والأثر التجاري، وسؤال التفاعل المجتمعي.

4. **إنفوجرافيك Nano Banana Pro:**
   - تصميم تحريري بنمط 3 بطاقات وبأبعاد 16:9 يبرز المفاهيم التقنية بدقة.
   - إرسال بوست متكامل واحد (صورة + نص منسق) على تلجرام.

5. **جاهز للنشر الفوري على Railway:**
   - يتضمن `Procfile` و `railway.json` و `.gitignore` مهيأة للإطلاق بنقرة واحدة.

## 🚀 التشغيل السريع محلياً

```bash
# تثبيت الاعتماديات
pip install -r requirements.txt

# تشغيل خادم لوحة التحكم
python -m uvicorn web_app.app:app --host 127.0.0.1 --port 8000 --reload
```

افتح المتصفح على الرابط: `http://localhost:8000`

---

## ☁️ النشر على Railway

1. اربط المستودع بحسابك على GitHub:
   ```bash
   git remote add origin https://github.com/USERNAME/linkedin-ai-publisher.git
   git push -u origin main
   ```
2. ادخل إلى **Railway.app** واختر **New Project** -> **Deploy from GitHub repo**.
3. أضف المتغيرات في لوحة Railway (Variables):
   - `GEMINI_API_KEY`
   - `LINKEDIN_ACCESS_TOKEN`
   - `LINKEDIN_PERSON_URN`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `FLOW_PROJECT_ID`
